# My project

Tell us more about your project below and how you built it!
This project is an example for our hack club students to show them how to make a simple website using HTML and CSS. How I built it was I first created my header wihch contained my name and some other info. Then, using CSS, I was able to align it to the center, create a background color, and make a cool 1 second hover color transition which inverted the colors.

Next I worked on the main body which included information about how I liked boba and where I like it from, and some other general info. Next, I defined what boba drops was. Then, I added a link to the boba drops requirements tab on the hack club wevsites events page and used target = "_blank" to make sure it opens on another tab, not replacing the current one because of the underscore. Finally, I added the boba drops event image. I also made the entire body section and the button for the boba drops requirement page also have their own separate color transitions when hovered. 

Throughout the project, I played around with many different font styles, background colors, text colors, and header types including h1, h2, and h3.
